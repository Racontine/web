🔑 Comment créer votre Clé de stockage ?

Pour que l'outil puisse envoyer vos sons sur GitHub, vous avez besoin d'un "Token" (une clé secrète).

  1. Créez ou connectez-vous à votre compte GitHub.
  2. Votre Nom d'utilisateur est celui qui s'affiche dans votre profil (ex: Racontine).
  3. Créez un Nouveau dépôt public (bouton "New" sur la page d'accueil) nommé par exemple commun.
  4. Cliquez sur votre photo (en haut à droite) et allez dans Settings.
  5. Tout en bas à gauche, cliquez sur <> Developer settings.
  6. Sélectionnez Personal access tokens > Tokens (classic).
  7. Cliquez sur Generate new token (classic).
  8. Nommez-le "Racontine" et cochez la case [x] repo.
  9. Cliquez sur Generate token en bas de page.
  10. ⚠️ IMPORTANT : Copiez le code qui s'affiche (il commence par ghp_). Vous ne pourrez plus le revoir !

Une fois terminé, remplissez les 3 champs (Utilisateur, Dépôt, Clé) et cliquez sur Sauvegarder.
